=============================================================
怎么验证
-------------------------------------------------------------
1) 编译并运行 C 版：

     cd native
     gcc -O2 -std=c99 nexus.c -o nexus
     ./nexus 900 12345

   输出里应该出现：

     hash@60=AD80AAA9
     FINAL_HASH=280F7260

2) 在浏览器里打开 index.html → 右侧「渲染后端」选 **C 内核 (C99)**
   面板上显示的 HASH 应与上面完全一致。

3) 或直接跑 JS 镜像：

     node test/c-hash.js

三个结果必须逐位相同。相同即证明：定点数运算、xorshift 随机、
状态机分支顺序、命中解算在 C 与 JS 两侧完全等价。

=============================================================
注意
-------------------------------------------------------------
· 哈希是逐字段 FNV-1a，不含结构体 padding，所以跨编译器/跨平台稳定。
· 改动 nexus.c 里任何一处数值或运算顺序，哈希都会变 —— 这正是它
  作为"回归测试"的价值：改完内核跑一遍，哈希变了就说明行为变了。
· 若要改基准，请同时更新本文件和 test/c-hash.js 里的期望值。
