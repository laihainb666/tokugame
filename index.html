🌐 网络对战怎么玩？

① 两个设备（或两个浏览器标签页）都打开本页面；
② 都点「账号中心」注册/登录账号，记下自己的 ID（THB-XXXX-XXXX）；
③ 一方点「网络对战 → ID 直连 → 创建房间」，把 ID 发给对方；
④ 另一方点「连接对方 ID」输入对方 ID 即可直连；
⑤ 客机选好角色点「准备就绪」，主机才能点「开始对战」。
