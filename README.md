## 🌐 联机架构（v14）

- **主机权威**：主机每 40ms 广播双方状态（state），客机每 33ms 转发输入（in）
- **客机渲染**：客机本地不做物理模拟，只渲染主机广播状态 + 线性插值平滑
- **信令**：PeerJS 公共信令（wss://0.peerjs.com）交换 SDP/ICE
- **打洞/中继**：多组公共 STUN + openrelay TURN 兜底（UDP/TCP）
